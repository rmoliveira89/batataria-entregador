MODO DE CONFIRMAÇÃO
Escolha como o entregador confirma o pedido:
Como funciona o modo ENTREGADOR:
1. Ao clicar em Localizador, abre modal com LOCALIZADOR preenchido
2. Botão 📋 COPIAR: copia, grava no Supabase e abre o iFood
3. Se estiver offline, a gravação fica na fila e sobe quando a internet voltar
4. No iFood cole o localizador e confirme a entrega
Cadastro na tabela config_custo_entregas. O ID é gerado automaticamente; você informa apenas o valor (R$).

create table if not exists config_custo_entregas ( id uuid primary key default gen_random_uuid(), custo numeric(10,2) not null, created_at timestamp default now() ); alter table config_custo_entregas enable row level security; create policy "libera tudo anon custo entregas" on config_custo_entregas for all using (true) with check (true);
